# Marble Rush (Android)

A portrait Android marble-racing game prototype built with Kotlin + Jetpack Compose.

## Features
- 30-second Sprint and 60-second Championship modes
- Up to 16 custom marble names
- Randomized obstacle layout each race
- Marble collisions, bumpers, moving obstacles, and a finish funnel
- Live countdown and final ranking
- GitHub Actions workflow that builds and uploads a debug APK

## Build on GitHub
1. Open **Actions** and run **Build Marble Rush APK** (or push to main).
2. Open the completed workflow run and download the `MARBLE-RUSH-APK` artifact.

Package: `com.peterrush.marblerush`
